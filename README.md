## ✨ **Key Features**

### 🤖 **Chathura.AI Assistant**
A dedicated **Floating AI Chatbot** that allows recruiters and visitors to interact with a digital version of me. It provides instant answers about my projects, contact details, and technical skills using intelligent intent recognition.

### 🍱 **Bento Grid Design**
A modern, Apple-inspired **Bento Grid** layout for the "About" section, organizing Experience, Qualifications, and Education into smart, responsive tiles with interactive hover effects.

### 🎨 **Interactive Tech Stack**
An attractive, touch-ready dashboard of my skills. Icons remain subtle in grayscale but burst into **brand colors with a neon glow** when hovered or touched.

### 🎭 **Marvelous Visuals**
- **Morphing Profile Shape**: An organic, fluidly animating profile photo container.
- **Glassmorphism 2.0**: Premium translucent cards with background blurs and 3D depth effects.
- **Magnetic Buttons**: CTAs that react to cursor proximity with physics-based movement.
- **Stardust Overlay**: A cinematic grain texture for added realism and depth.

### 🔄 **Dynamic Intelligence**
- **Auto-Updating Age**: Automatically calculates my current age based on my birthday (June 7, 2002).
- **Animated Typing Greeting**: Cycle of professional greetings including "Hey there!".
- **Smart Solutions Scenarios**: A dynamic chat simulation showing real-world AI use cases.
